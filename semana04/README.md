# Gestion de Vehiculos

## Descripcion

Gestion de Vehiculos: clase abstracta Vehiculo, subclases Auto/Moto/Camion, interfaz Electrico implementada por AutoElectrico, recorrido polimorfico de ArrayList<Vehiculo>.

## Como se ejecuta

cd src
javac modelo/*.java app/GestionVehiculos.java
java app.GestionVehiculos

## Que se aprendio

- Herencia (extends/super), polimorfismo (Override, upcasting, binding dinamico)
- Clases abstractas vs interfaces
- toString/equals/hashCode de Object
- instanceof con pattern matching (Java 16+)
