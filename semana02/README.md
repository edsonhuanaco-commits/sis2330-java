# Sistema de Calificaciones

## Descripcion

Sistema de Calificaciones: arrays 2D, metodos static, Scanner con validacion de InputMismatchException.

## Como se ejecuta

cd src
javac SistemaCalificaciones.java
java SistemaCalificaciones

## Que se aprendio

1. JVM/JRE/JDK: el JDK compila (javac), el JRE ejecuta (java), la JVM traduce bytecode a instrucciones nativas.
2. 8 tipos primitivos: byte, short, int, long, float, double, char, boolean.
3. Division entera vs decimal: 7/2 = 3, 7.0/2 = 3.5.
4. Cortocircuito: && y || se detienen apenas el resultado es seguro.
5. Arrays: tamano fijo, acceso O(1) por indice. Los 2D son arrays de arrays.
6. Sobrecarga vs sobrescritura: sobrecarga = mismo nombre, distinta firma. Sobrescritura = redefinido en clase hija.
